# Testing checklist for community and low-literacy users

Test with consent. Do not collect real identity or financial data. Use only fictional amounts and sample stories. Ask participants what is confusing; do not treat a wrong answer as a user failure.

## First-use test

- [ ] Can a new user understand the core rule without a facilitator explaining it?
- [ ] Can the user choose daily, weekly/shop or invoice/project in under three taps?
- [ ] Does the learner recognise the livelihood pictures as examples, without assuming that a picture defines their occupation?
- [ ] Can the user switch English ↔ हिन्दी and return without losing their progress?
- [ ] Are the English and Hindi labels consistent and readable on a 360px Android screen?

## Floor Number test

- [ ] Can the user enter rupee amounts in all four fields?
- [ ] Does the total update immediately and include work cost?
- [ ] Is it clear that this is one month's minimum need, not a goal or a recommended budget?
- [ ] Can a user leave the weak-month income blank and continue?
- [ ] Does the Reality Check use kind, non-shaming language when income is below the Floor Number?

## Teach and quiz test

- [ ] Does every tier show its correct work sequence?
- [ ] Does each card explain one idea in short language, include a rupee example, and end with an action?
- [ ] Are examples visibly marked “Illustration only / सिर्फ उदाहरण”?
- [ ] Are there exactly three questions for each tier and extra module?
- [ ] Does the answer feedback explain why, without a shaming score?
- [ ] Does the voice button work in both language settings on the test phone?

## Practice simulator test

- [ ] Can the learner select a box and add ₹50, ₹100 or ₹200 by tapping?
- [ ] Can the learner drag a coin on a desktop and still use the tap path on a phone?
- [ ] Can amounts be typed directly into each box?
- [ ] Does the app show unassigned money and warn when allocated amounts exceed money received?
- [ ] Is there no default percentage split presented as a rule?
- [ ] Is the work/home/buffer meaning still clear if colour is unavailable?

## My Plan and privacy test

- [ ] Can the learner save and re-open their plan on the same device/browser?
- [ ] Do the four pledges and seven day checks persist after a refresh?
- [ ] Does the habit badge depend on repeating daily checks, not the amount saved?
- [ ] Does the printable page show all plan fields and the five questions?
- [ ] Does the Clear my saved plan control remove this module's saved local data?
- [ ] Is the shared-phone warning visible?
- [ ] Confirm that no account number, PAN, Aadhaar, PIN or OTP field exists.

## Access and device testing

- [ ] Test on a low-cost Android phone at 360 × 640 and 393 × 852.
- [ ] Test with slow or no network after the first successful load; confirm that cached pages and assets open.
- [ ] Test the module in Chrome and at least one other common Android browser.
- [ ] Use Android screen reader/TalkBack to move through headings, form labels and buttons.
- [ ] Check keyboard focus, contrast and large-text mode.
- [ ] Try listen-first mode and confirm the main action remains visible.
- [ ] Confirm that links to official schemes open separately and are not confused with an in-app approval.

## Feedback questions

1. “What would you do first when money comes in?”
2. “Which box was hard to understand?”
3. “Was there a word or picture that did not fit your work?”
4. “Could you use this again without a teacher?”
5. “What would make it easier on your phone?”

Make one change at a time, retest both languages, and keep a date-stamped note of the change.
