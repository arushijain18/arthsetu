# ArthSetu live preview

Run the full React application locally:

```bash
cd client
npm install
npm run dev
```

Open the Vite URL (normally http://localhost:5173), enter through the door, sign in or create an account, then choose a category. **Fraud lab** opens inside the ArthSetu shell. The module files are in `client/public/fraud-labs/`.

A standalone integrated-flow preview is supplied separately as `ArthSetu-Fraud-Labs-Integrated-Preview.html`. It includes the door-entry interaction, category selection and a working embedded Fraud Labs module. Other categories in that lightweight preview are representative navigation cards; the full modules run in the complete Vite project.
